# 试点执行与合规草案

## 试点与评价

首发使用 SaaS / 互联网销售运营模板。三家试点每家选两个关键岗位，先完成启动会，确认交接人、接班人、负责人、截止日期、独立替代者和资料范围。超出模板范围的岗位在真实接入前由领域顾问标注并审核可用性。

每个岗位按盘点、访谈、交接包、验收、复核、签署顺序交付。签署后 30、60、90 天回访。30 天检查接班人是否能独立处理至少 80% 事项，并记录遗漏、返工和遗留风险处置。访谈完成率低于 80% 或两周无法完成一个岗位盘点时复盘模板和问法。

| 试点证据 | 采集方式 | 门槛 |
|---|---|---|
| 端到端闭环 | 记录报告版本和三方签署时间 | 3 家试点、6 个岗位 |
| 资产质量 | 双人标注真实关键资产并核对每条出处 | 召回 ≥90%，编造 ≤2% |
| 题库与评分 | 题目盲审，人机双评，记录争议样本 | 可用率 ≥80%，κ ≥0.6 |
| 交接体验 | 完成耗时、首考通过率、NPS 与回访 | ≤3 小时访谈，首考 ≥70%，NPS ≥30 |
| 商业证据 | 组织签署的合同或试点意向书 | ≥2 家付费或签 LOI |

脱敏案例须获得客户的明确发布许可。对外仅展示岗位类别、范围、结论及经核查的变化量，移除个人姓名、联系方式、客户名称、供应商和内部地址。

## 五分钟演示

1. 打开总览，指向华东区销售运营的红灯。查看续费折扣审批未通过以及一票否决证据。
2. 展示证据来源和三轮访谈。切换接班人，在交接包搜索关键事项和联系人。
3. 负责人填写补交接证据。接班人完成补考，负责人复核并生成新版报告。
4. 展示三方已签署的示例岗位。申请脱敏报告并用人力资源角色审批，查看 PDF 水印和审计记录。

销售沟通围绕可验证的交接结果。现有知识库继续保存制度文件，接棒验证接班人能否找到资料并处理例外。试点报价、计费起点、交付范围、取消、退款及违约处理须写入双方订单，按 PRD 第 11 节由产品与法务审批。

试点洽谈沿用 PRD 的评审价。自助版为每岗位每月 199 元，团队版为每年 1.2 万元，企业版为每年 8–30 万元，陪跑服务为每次 2–5 万元。正式订单填写岗位数量、服务范围、计费起点、税费、取消和退款条件、核算方式及到账期限，双方核准后执行。

## 告知与隐私政策草案

运营主体 `[法定名称]` 负责处理岗位交接所需信息，联系方式为 `[负责部门及联系方式]`。处理范围包括参与人名称和角色、交接资产及必要证据、访谈、答题和手写签署记录。处理用于交接、风险核对、签署及审计。请勿提交账号密码、私钥、底价等高危原值。

岗位记录默认在归档后保存 24 个月，可依正式协议与法规另行约定。申请获批准后限制访问并移除资料，备份按约定周期清理。为核对删除和安全事件保留最低必要的审计信息。

## 用户协议与数据处理附录草案

- 双方以签署订单约定开通期限、岗位范围、费用、计费起点、提前终止和退款处理。客户指定有权审阅及批准导出的人员，参与人在录入前核对敏感级别和来源。
- 数据处理指令仅限签署订单和工作台中的授权设置。运营方在约定区域处理最低必要数据，使用访问控制、传输与存储加密、审批水印和审计。子处理者清单、地区、期限和数据流向在 `[配置清单]` 中列明，启用前按协议确认。
- 约定数据访问请求、事件通知时限、审计协作、终止时返还与删除流程、备份保留周期，以及密钥交接和恢复责任。上线前由运营主体与客户法务填齐 `[责任人]`、`[期限]`、`[渠道]` 和 `[争议约定]`。
- 交接报告仅覆盖所列证据、系统和时段。负责人和接班人核对结论及未覆盖项。产品记录交接事实和风险处置责任。确认书不替代离职证明，记录不用于员工绩效评价。
